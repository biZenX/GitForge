Engineered Differently

Built for Real Development on Mobile.

No artificial web compromises. GitForge combines low-level Android system capabilities with official GitHub platform APIs.

Pure Native Eclipse JGit Engine

Direct local repository management with zero NDK binary crashes. Full HTTPS clone, commit, branch switching, staging, unstage, and unified diff generator executing directly on your device.

$ git status
✔ Clean working tree on branch 'master'
Verified on Eclipse JGit 6.10 with JDK 21 desugaring

Hardware Keystore Security

Zero hardcoded secrets. All Personal Access Tokens and OAuth credentials are encrypted with AES-256 GCM backed by the Android hardware Keystore.

🛡️ AES-256 GCM Encrypted

Syntax-Highlighted Studio

Edit Kotlin, Java, Python, JS, and Markdown with line numbers, find-in-file, undo/discard safeguards, and side-by-side diff previews.

WorkManager Background Sync

Streaming ZIP archive downloads with Foreground Service notifications and periodic offline Room caching when connected.

Archive Downloader Streaming ZIP

Confined Shell Terminal

Dual-mode command runner with built-in sandbox commands and strict path-traversal prevention. Never escapes app storage.

$ pwd
/data/user/0/io.gitforge.app/files/workspaces
Under The Hood

Clean Architecture. Zero Slop.

Strict unidirectional data flow, modular Kotlin libraries, and test coverage across presentation, domain, and data layers.

UI

Jetpack Compose BOM
