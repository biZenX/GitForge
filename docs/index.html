Layered Architecture

Clean Unidirectional Flow

GitForge is structured into modular Gradle modules with clear boundaries. Presentation layers never talk directly to networks or local SQLite engines; ViewModels expose immutable StateFlows to Jetpack Compose.

:app

Main application entry, Navigation Compose graph, Hilt dependency injection roots.

:core:model

Immutable domain data models (Repositories, Users, Commits, Issues, PRs).

:core:network

Retrofit, OkHttp conditional caching, GitHub REST & GraphQL API clients.

:core:security

Android Keystore-backed encrypted token storage and OAuth callback handlers.

:core:designsystem

Material 3 Expressive theme, Squircle shapes, Wafeer metric cards, and diff viewers.

:feature:git

Pure JGit 6.10 engine for local clones, staging, committing, branching, and pushing.

:feature:editor

Multi-tab Code Studio with regex syntax highlighting, line numbers, and buffer recovery.

:feature:terminal

Sandboxed on-device shell session with process isolation and stdout/stderr capture.
